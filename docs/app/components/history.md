# History Components (`app/src/components/history/`)

## 1. `PreviousInterviewsList.tsx`
- **Purpose**: Displays stored sessions from `localStorage` on the home dashboard.
- **Card Metadata**:
  - Job Title & Company Name
  - Status Badge (`Completed` / `In Progress`)
  - Candidate Name, Attached CV filename, and creation timestamp
  - Direct shareable link path (`/interview/:id`)
  - Clear history action
